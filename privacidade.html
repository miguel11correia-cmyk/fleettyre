Política de Privacidade

Última actualização: Julho de 2026

1. Quem somos

O FleetTyre é uma aplicação de gestão de pneus para frotas de veículos pesados e reboques, disponibilizada por Miguel Correia. Para questões sobre privacidade, contacta miguel.11.correia@gmail.com.

2. Dados que recolhemos

Recolhemos os dados que introduzes directamente na aplicação: email e credenciais de acesso, dados da tua empresa, registos de pneus (matrículas, custos, fornecedores, marcas), e dados de utilização da aplicação. Não recolhemos dados de pagamento nem dados sensíveis de terceiros além do necessário para a gestão da frota.

3. Para que usamos os dados

Os dados são usados exclusivamente para prestar o serviço de gestão de pneus: autenticação, cálculos de custo e desgaste, alertas, análises, e separação dos dados entre empresas clientes. Não vendemos nem partilhamos dados com terceiros para fins de marketing.

4. Onde os dados são guardados

Os dados são guardados numa base de dados gerida através da Supabase, com acesso restrito por autenticação e políticas de segurança ao nível da base de dados (cada empresa só acede aos seus próprios dados).

5. Os teus direitos

Nos termos do RGPD, tens direito a aceder, corrigir, exportar ou solicitar a eliminação dos teus dados. Para exercer estes direitos, contacta-nos pelo email acima.

6. Cookies e armazenamento local

A aplicação usa armazenamento local do browser (localStorage) apenas para guardar a tua sessão e a empresa seleccionada — não usamos cookies de publicidade ou de rastreio de terceiros.
